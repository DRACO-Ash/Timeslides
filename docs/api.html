Conventions

  • Errors share one shape, {"error": "<Type>", "detail": "<sentence>"}: 400 ValidationError, 404 NotFoundError, 409 ConflictError, 422 ComputeError, 500 ConfigError, 502 UpstreamError (the UDL refused, rate limited or failed). A malformed body is refused by the framework with 422 before any code runs.
  • Authentication: the application performs none of its own and holds no user accounts. FACTNo route checks a token. INFERENCEAccess is controlled by the App Store's sign-in front door, which passes X-Auth-Request-Email; the app records that address in its request log line and nothing more.
  • UDL credentials come only from UDL_USER and UDL_PASS in the environment. Callers of this API never supply or see them.
  • Inbound rate limits: none. Outbound UDL calls are paced by a token bucket, 60 per minute by default (UDL_RATE_PER_MIN).
  • Demo mode (TIMESLIDES_DEMO=1, or a DAST scan with no credentials) answers every UDL-backed route with synthetic data and sets "demo": true.
  • Documentation routes are off: /docs, /redoc and /openapi.json return 404. This page is the reference.
  • Data modes: REAL, SIM (sent to the UDL as SIMULATED), TEST, EXERCISE.
  • Logging: one JSON line per request on stdout, in the App Store logging standard. Query strings, cookies and the Authorization header are never logged.

Interface and health

GET/Local

The application page: the group picker, render controls and report viewer. It is also the platform's readiness probe target, so it is built from local assets and never calls the UDL. A UDL outage therefore cannot put the pod into a restart loop. The page carries the configured classification banner and warns if storage has fallen back to memory.

GET/healthzLocal

Always 200 while the server runs, even when the volume cannot be written, because the pod can still render reports. The storage block says how the volume was probed at boot.

{"status": "ok", "demo": false,
 "storage": {"writable": true, "mode": "volume" | "memory", "strategy": "...",
             "detail": "...", "path": "/data/groups.json"}}

Groups

A group is a named set of objects with one reference object, which is the datum every phase offset is measured from. The store is one versioned document: each change increments rev. Pass the rev you last read on writes, and if someone else changed the document since then you get 409 instead of overwriting their work. Omit it to write regardless.

GET/api/groupsLocal
Query parameters

includeArchived (default false): include archived groups.

Response
{"rev": 7,
 "groups": [{"id": "uuid", "name": "Proximity operations", "sats": [62902, 62903, 62904],
             "reference": 62902, "archived": false, "created": "...", "updated": "..."}]}
POST/api/groupsWrites
Body (JSON)
FieldRule
nameRequired. Up to 80 characters once cleaned
satsRequired. 2 to 40 NORAD catalogue numbers, each 1 to 999,999,999
referenceOptional. Must be one of sats. Defaults to the first
revOptional, ignored on create
Example
curl -s -X POST "https://<timeslides-host>/api/groups" -H "Content-Type: application/json" \
  -d '{"name":"COSMOS 2581 cluster","sats":[62902,62903,62904],"reference":62902}'
Responses

201 with the new group record · 400 for a bad name, count or reference

PUT/api/groups/{group_id}Writes

Replaces the group's name, objects and reference. Its created time and archived state are kept. Body as for create, with rev for the conflict check.

Responses

200 with the updated record · 400 invalid · 404 no such group · 409 the document changed since your rev

DELETE/api/groups/{group_id}Writes

Archives the group rather than deleting it: it disappears from lists and renders and can be restored. Nothing is ever hard-deleted through the API.

Query parameters

rev (optional): the conflict check.

Responses

200 with the archived record · 404 · 409

POST/api/groups/{group_id}/restoreWrites

Un-archives a group. Query parameter rev as above.

Responses

200 with the restored record · 404 · 409

GET/api/sources/probeUDL

Asks the UDL, provider by provider, whether any state vectors exist for an object. Provider names are configured, not read back from the tenant, so a misspelt one silently returns nothing and never appears in a report. This route makes that visible. It makes one small request (maxResults=1) per provider.

Runs and reports

A render never runs inside a request. POST /api/runs queues it and returns at once; poll the run until status is done, then fetch the report. The last 50 runs are remembered.

POST/api/runsUDLWrites

Queues a phase offset waterfall render. If an identical render is already queued or running, the call joins it and returns that run with "joined": true rather than starting a second.

Body (JSON, camelCase or snake_case)
FieldDefaultMeaning
groupIdsevery live groupUp to 12 group ids. An archived group is refused with 400
days7Window length, 1 to 90, ending at end
start, endend = nowISO 8601. A naive time is read as UTC. start overrides days. The window may not exceed 90 days
modes["REAL"]Any of REAL, SIM, TEST, EXERCISE
sourcesall five state sourcesKeys from /api/sources. Element sets are always fetched: they carry the reference orbit
invertfalseFlip the sign convention of the offsets
Example
curl -s -X POST "https://<timeslides-host>/api/runs" -H "Content-Type: application/json" \
  -d '{"groupIds":["<uuid>"],"days":7,"modes":["REAL"],"sources":["leolabs","spacetrack"]}'
Response
202 {"id": "<run_id>", "status": "queued", "label": "COSMOS 2581 cluster",
     "created": "...", "started": null, "finished": null, "error": null,
     "progress": {"done": 0, "total": 0, "current": ""}, "reportUrl": null, "joined": false}

400 for a bad window, mode, source or group, or no groups defined · 404 unknown group id

GET/api/runsLocal

The remembered runs, each in the run shape below.

{"runs": [{"id": "...", "status": "done", ...}, ...]}
GET/api/runs/{run_id}Local

One run's state. status moves through queued, running, then done or failed. progress counts objects fetched and names the current one. reportUrl is set once the run is done, and error carries the reason for a failed run.

{"id": "...", "status": "running", "label": "...", "created": "...", "started": "...",
 "finished": null, "error": null, "progress": {"done": 2, "total": 3, "current": "COSMOS 2582"},
 "reportUrl": null}

404 for an unknown run id

GET/api/runs/{run_id}/reportLocal

The finished report: a self-contained HTML document with the waterfall plot, object cards, the Look-ahead forecast and pass list. It is several megabytes, streamed from the volume, or from memory if the volume refused it.

Caching

Returns ETag: "<run_id>" and Cache-Control: private, max-age=3600. A report never changes once written, so sending the ETag back as If-None-Match returns 304.

Responses

200 text/html, served inline as phase_offset_<id>.html · 304 · 400 the run is not finished yet · 404 unknown run

Manual state

POST/api/manual-stateLocal

Places one hand-entered state vector or element set against a report's reference orbit and returns where it lands. It is entirely stateless: nothing is stored, nothing is fetched from the UDL, and the report on the volume is untouched. The report draws the result as a temporary, highlighted point. The audit log records that a placement happened, not what was entered.

Body (JSON)
FieldMeaning
kindstate (default) or elset
epochState vector epoch, ISO 8601 UTC
frameState vector frame, default J2000
x, y, zPosition, km (text or number)
vx, vy, vzVelocity, km/s
elsetA pasted two- or three-line element set, up to 400 characters
labelOptional display name, up to 200 characters
tleRequired: the report reference's two TLE lines, which the report page supplies
invertMatch the report's sign convention
Response
{"kind": "state", "offset": -12.345, "km": -93.1, "epoch": "...", "detail": "...",
 "label": "...", "trace": {...Plotly marker...}, "row": {...table row...}}

400 with a sentence naming the bad field (an unparseable number, a bad checksum, a velocity below orbital speed)

Outbound UDL calls

The UDL is Timeslides' only external dependency. Requests use HTTP Basic credentials from the environment and are paced by the outbound token bucket. Timestamps are sent as YYYY-MM-DDTHH:MM:SS.000000Z.

UDL endpointCalled byParameters
GET /udl/statevectorEach render: once per object, per selected source, per data modeepoch=<start>..<end>, satNo, source, maxResults (5000), dataMode
GET /udl/elsetEach render: once per object, per data modeepoch=<start>..<end>, satNo, maxResults (5000), dataMode. Not filtered by source
GET /udl/statevector/api/sources/probe: once per providerAs above with maxResults=1
GET /udl/onorbit/api/catalogue, and object names for a rendersatNo=<n,n,...> for a number; name=~<TEXT> with maxResults for a name
Example: element sets for COSMOS 2581 (62902), default 7-day window
https://unifieddatalibrary.com/udl/elset?epoch=2026-11-17T00:00:00.000000Z..2026-11-24T00:00:00.000000Z&satNo=62902&maxResults=5000&dataMode=REAL
FACTThe /udl/onorbit field names and the provider source strings come from the public UDL data model, not from a call against the tenant. A provider spelt differently by the tenant returns an empty list, not an error. Use /api/sources/probe to check.

Read once at boot from the environment. There is no configuration file. Missing credentials stop the application at boot, except in the DAST scan case.
